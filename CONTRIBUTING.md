# Comment contribuer au dépôt ?

## Corriger une coquille, une erreur...

Deux options : 
* ouvrir une Issue, donner la page et la ligne et proposer une correction
* ouvrir une Pull Request, proposer une correction

## Ajouter une fonctionnalité

* Avant de commencer, ouvrez une Issue pour décrire la fonctionnalité envisagée — cela permet d'en discuter et d'éviter un développement qui ne serait finalement pas retenu.
* Créez votre branche à partir de `main`, avec un nom explicite (ex. `feature/export-pdf`).
* Respectez les conventions déjà en place dans le projet, détaillées dans la section « Conventions » du `README.md`.
* Gardez la Pull Request ciblée : une fonctionnalité = une PR, avec des commits clairs plutôt qu'un unique gros commit.
* Testez votre modification localement avant de proposer la PR.
* Décrivez dans la PR ce qui change, pourquoi, et comment le tester.
* Restez disponible pour les retours de relecture — une PR peut demander quelques allers-retours avant d'être fusionnée.

En vous remerciant d'avance pour vos contributions !
